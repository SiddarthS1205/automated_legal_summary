PDF Generation Test

This is a simple test to verify jsPDF is working correctly.

Instructions:

  1. Click the "Test PDF Download" button
  2. A PDF file should download (NOT a TXT file)
  3. Open the PDF - it should show "Hello PDF!"
  4. If it works here, the main app will work too after clearing cache

If it doesn't work:

  • Check your internet connection (jsPDF loads from CDN)
  • Open browser console (F12) and look for errors
  • Try a different browser
